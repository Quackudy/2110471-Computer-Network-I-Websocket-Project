R1 · Protocol choices

ProtocolWhy and how
IP + TCPRoute data between hosts; provide a reliable, ordered transport.
HTTPSServe the browser client and establish the WebSocket upgrade handshake.
WebSocket / WSSPersistent, bidirectional framed messages. Every chat command and delivery uses /ws.
JSONApplication event format inside WebSocket frames, including room IDs and message bodies.
TLSEncrypt browser-to-proxy traffic; internal socket traffic stays on the Docker network.
SSH + HTTPS registryAuthenticated deployment connection and pulling the container image from GHCR.
Internal HTTPRequest AI inference from Ollama; it is not the client chat transport.

The server derives the sender from the socket session, checks room membership, and delivers only to the room’s members. A third client cannot send, read or summarize this private room.

def authorized_room(self, client, data):
    room_id = data.get("room")
    room = self.rooms.get(room_id) if isinstance(room_id, str) else None
    if room is None or client.id not in room.members:
        raise ValueError("Join this room before using it.")
    return room
